# Oathbound — Cursed Salvage SFX v1

24 original procedurally synthesized prototype effects. No external samples.
48 kHz, mono, 16-bit PCM WAV. Peaks below -1.5 dBFS. Dry sounds for positional playback.
Firearms: fire, reload (stylized full sequence), dry_fire.
Blades: swing, impact (hard metallic target), draw.

Bagyo: sharp rattling report. Baga: rough heavy crack. Tanod: bright long report. Hatol: low booming report. Daluyong: dense cutting rush. Silakbo: brighter ringing slash. Salin: broad heavy sweep. Tinig: thin eerie resonance.

Import individual WAVs into Godot and trigger with AudioStreamPlayer3D. Fire is a single shot; schedule repeated shots at the weapon fire rate. Trigger blade swing and impact separately. Reload timing needs alignment with animation. No gameplay integration performed. Technical signal checks do not replace listening and in-game mixing.
